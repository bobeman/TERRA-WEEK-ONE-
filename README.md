# TERRA-WEEK-ONE-
coding a snake game
(how to play) to play you can use arrow key and space bar, as of now really only the snakes movement  works, the score tracking has not been completed.

Steps to build
- next i imported three.js and set up my scene camera and renderer with lighting
- after that i made the platform for the snake and a box line for the play area
- then i coded the objects like the snake head rats rocks and trees
- after that i made the movement mechanics to handle how the snake slithers
- i built the animate loop to render everything
- next i wrote the functions to randomly spawn the rocks and rats on the grid
- then i added keyboard controls so the snake can turn and jump using space

- finally i made the camera follow the snake
